# OpenAI Codex Official Plugins Marketplace for Claude Code

Official OpenAI Codex curated plugin marketplace adapted for Claude Code and Claude Desktop.

## Overview
This marketplace provides all 120 official OpenAI Codex curated plugins (including Linear, Slack, GitHub, Stripe, Vercel, Figma, Airtable, Notion, and more) formatted for seamless integration with Claude Code and Claude Desktop.

## Usage in Claude Desktop
Add the following to your Claude configuration:
```json
{
  "source": "github",
  "repo": "juzipi-links/codex-plugins"
}
```
